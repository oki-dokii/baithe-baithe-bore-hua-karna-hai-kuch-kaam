# Terminal-position search and telemetry-quality dossier

The offset atlas now offers two explicit search bases. The default remains surface wellhead radius. `proximity_basis=terminal_bottomhole` compares the terminal horizontal positions reconstructed from *reviewed, version-bound, true-north* surveys. In this mode the server does **not** prefilter by surface distance: a surface-far well can enter if its terminal point falls inside the radius. Missing or unreviewed candidate surveys are excluded and counted; an unresolved active survey stops the request. A dataset with more than 1,000 possible wellbores stops rather than returning an incomplete search, and results are capped at 100 with a truncation flag. Map markers still denote surface wellheads, not terminal points.

This is endpoint proximity only. It has no uncertainty ellipses, closest-approach scan, common-datum reconciliation, or collision-clearance assessment. The synthetic fixture has reviewed *demo geometry* for A/B only. The UI and printable brief carry the search basis and warning, and the default surface behavior remains unchanged.

`GET /api/v1/telemetry-sources` lists staged historical sources. `GET /api/v1/telemetry-sources/{id}/quality-dossier` reruns the versioned drilling-ahead screen on the latest revision of each source record and reports blockers, completeness, active-drilling fraction, depth advance, ROP/WOB ranges, gaps, quality and rig-state counts, review flags, and source-qualification state. The dossier is read-only, excludes raw sensor values and permission references, and stops live screening above 100,000 stored revisions. A screen pass does **not** establish event labels, engineering qualification, ML training permission, or deployment readiness.

Verification: unit tests, frontend build, and focused database-backed integration tests on a newly migrated isolated database. The terminal search test places an owned synthetic offset outside the surface radius while its reviewed synthetic terminal point is inside; the surface search excludes it. No real survey or telemetry suitability was validated.
