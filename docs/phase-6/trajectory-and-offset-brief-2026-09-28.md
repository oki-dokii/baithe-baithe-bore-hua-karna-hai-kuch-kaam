# Trajectory positions and offset brief — bounded first release

`minimum_curvature_true_north_v1` integrates inclination and azimuth between MD stations into local north/east offsets. The pairwise API projects each endpoint from its verified surface coordinate with PostGIS, then measures horizontal bottom-hole separation. This is **not** anti-collision clearance: it contains no survey uncertainty, positional ellipse, closest-approach scan, common vertical datum comparison, or collision-risk decision. The analogue search still selects by **surface radius**; the pairwise separation is shown only for a surface-selected pair.

Position output fails closed unless each wellbore has at least two complete stations starting at MD 0, consistent MD/TVD increments, an explicitly recorded **true-north** azimuth reference, and an approved metadata record bound to the latest `survey_version`. `grid` and `magnetic` references are stored but unresolved until a reviewed conversion is implemented. The reference approval record requires a reviewer and evidence reference. Existing real reports default to `unreviewed`; no real positions were fabricated or backfilled. Only the owned vertical golden-fixture pair can receive the separate, audit-logged [synthetic demo attestation](rehearsal-0017-2026-09-28.md), which is labeled synthetic-only in the UI. A later survey version invalidates the positional calculation until the reference is reviewed again. The new API is `GET /api/v1/wellbores/{id}/bottomhole-proximity?offset_wellbore_id={id}`; it returns reason codes rather than a made-up distance.

The `offset-brief` endpoint and editorial print panel provide a bounded handover artifact: up to three surface-selected offsets and six resolved, approved, cited historical event claims. It prints source filename, page and passage ID, provenance/applicability, historical and mapped MD, and explicit non-recommendation wording. Uncited and unresolved claims are excluded and counted. If content is capped, a visible truncation notice directs users back to case files. No LLM, hazard probability, assumed rig rate or generated drilling instruction is involved. Print CSS targets A4; browser/PDF pagination should still be visually checked on realistic data before calling it a guaranteed one-page output.

Next trajectory step: ingest real surveys with explicit north reference and reviewer-backed metadata, then build a candidate-discovery mode that can search by bottom-hole proximity (with spatial indexing and uncertainty) rather than only reporting pairwise endpoint separation. Do not call the current endpoint a field-grade anti-collision tool.
