The local clean preview URL is `http://127.0.0.1:13003/` while its host processes remain running. It uses the same role tokens as the ignored root `.env`; never commit them. This setup is not a full new Compose-volume rebuild: the existing database container and 280 MiB-free volume were reused, with a new database inside it to avoid a risky image/volume duplication. The old Docker web preview is not the validated path.

For this already prepared database, `bash scripts/demo-up.sh` is the repeatable local launch command. It refuses occupied ports, production mode, a mixed dataset or anything other than exactly one approved, cited synthetic claim; it checks the cached model offline, idempotently indexes that claim, then starts API, ingestion/index worker, replay worker and Vite. Keep the terminal open; Ctrl-C stops only those four child processes. Initial creation of a new empty DB and the guarded `nwis.demo_rehearsal` are separate one-time steps—do not rerun the latter against a populated database.
